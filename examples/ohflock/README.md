# OHFLOCK

Twenty-four unarmed kites hold a relief corridor open with light on sensors, thrown sound and SatLink.
Open [ohflock.html](ohflock.html) for the 3D replay, or read [docs/OHFLOCK.md](../../docs/OHFLOCK.md).

```bash
./build/ohflock --html build/ohflock.html
./build/ohflock --serve 1987        # then: gyde --url http://127.0.0.1:1987
```
