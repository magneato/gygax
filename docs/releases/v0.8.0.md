# Gygax 0.8.0: Oliphaunt — Never Forgets

Operation Oliphaunt adds persistent, privacy-conscious memory for recurring sightings, with a CLI, service tools,
safe places, trust and erasure controls, and a Quest AR overlay. Findings are evidence to review, not proof of intent;
the capture hook is opt-in and does not recognize or retain images.

- `docs/OLIPHAUNT.md`: engine, privacy boundaries, CLI, service tools and AR controls.
- `docs/GLYDER.md`: passthrough AR, accessible base mode and experimental camera capture.
- Quest APK: `glyder-0.8.0-quest.apk`.

Base mode provides a plain view and sound-first cues for a low-vision wearer or a helper, while preserving the wearer's
vision correction and colour filters. It can be switched on and off from glyder's menu.

Gygax is pre-1.0; interfaces may change between minor releases. Please report issues at
[magneato/gygax](https://github.com/magneato/gygax/issues).
