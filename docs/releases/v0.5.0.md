# Gygax 0.5.0: Matrix Refactored

0.5.0 rebuilds the front door of glyder and opens Gygax to local language models. The Construct now has four
scenes you can switch between from the lobby or the in-world menu. `gygax mcp` makes every Gygax tool available to
LM Studio and other MCP clients, and Gygax can now drive a Unitree Go2 quadruped.

Gygax is pre-1.0: interfaces may still change between minor releases, and the release notes will say how. Please
report what breaks: [issues](https://github.com/magneato/gygax/issues). 0.5.0 follows 0.4.0 "Matrix".

## glyder scenes

The lobby and the menu (Y on the left controller, Tab on a desktop) have a **SCENES** row:

| Scene | Where it runs | What it is |
|---|---|---|
| CALM | in the headset | the Construct on slow, predictable routines; nothing flashes |
| CHAOS | in the headset | a hive swarm in waves, missiles arcing in and bursting, turrets firing tracers, fast drones to drop into |
| OHFLOCK | your computer | jumps to an `ohflock --glyder` host on the network |
| LIVE | your computer | jumps to a `gygax serve --glyder` host: your real machines |

Calm and Chaos need no computer, and switching between them doesn't reconnect: the host sends the new world to
every connected headset (`glyder::Host::reconfigure`). If no OHFLOCK or Live host is running, glyder tells you what
to run. The desktop viewer's `--script` takes `scene NAME` for headless captures.

## Gygax in LM Studio (MCP)

```sh
gygax mcp            # an MCP server on stdin/stdout
```

Add it to `~/.lmstudio/mcp.json`:

```json
{ "mcpServers": { "gygax": { "command": "/path/to/gygax", "args": ["mcp"] } } }
```

Any model with tool use can then call Gygax's tools: `math__eval`, `time__now`, `device__list`, `logistics__plan`
and the rest. Several calls at once run in parallel on worker threads pinned to neighbouring cores
(`--mcp-workers N`). Every `serve` option works here too, so devices, plugins and other MCP servers can be exposed
as well. See [docs/LMSTUDIO.md](../LMSTUDIO.md).

## Unitree Go2

`--device dog=unitree_go2:udp://192.168.123.161:8082` registers a Go2. Commands go through the device gate
(`--device-commands`): stand, sit, damp, stop, move/twist, recovery stand, gait, body height, and gestures. The
driver reports mode, pose, attitude, foot forces and battery, and glyder shows the Go2 as a quadruped you can drop
into.

## Upgrading

- `glyder::DemoWorld::start` takes an optional scene; `setScene` and `scene` are new.
- `glyder::Client::worldRevision()` changes when the host switches worlds mid-session.
- `service::serveMcp` takes an optional worker count, and `McpServerTool` has an optional `inputSchema`.
- The Quest APK is `glyder-0.5.0-quest.apk`. Install it with `adb install -r glyder/glyder-0.5.0-quest.apk`.

The full list is in the [changelog](../../CHANGELOG.md).
