# Gygax 0.7.0: OSINT & Autonomous Reconnaissance

0.7.0 adds the OSINT and geolocation module: a hierarchical event engine, EXIF/IPTC image metadata parsing and
writing, photograph geolocation checks, four service tools and a working `recon_survey` example. Details:
[docs/OSINT.md](../OSINT.md).

- The 0.6.0 tag shipped without these sources; they are here now, with unit tests.
- `recon_survey` no longer needs OpenCV; it runs a terminal HUD.
- Install the Quest app with `adb install -r glyder/glyder-0.7.0-quest.apk`.

Gygax is pre-1.0: interfaces may still change between minor releases. Please report what breaks:
[issues](https://github.com/magneato/gygax/issues). 0.7.0 follows 0.6.0.
