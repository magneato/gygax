# Gygax 0.2.0 alpha 1: Genesys

The first public release of Gygax: one C++26 program for building autonomous systems that run on **your** hardware,
with **your** models, under **your** control.

This is an **alpha**. Everything listed below is built and tested, but interfaces may still change before 0.2.0.
Please report what breaks: [issues](https://github.com/magneato/gygax/issues).

## What it is

* **A local AI service** (`gygax serve`). It routes chat requests to the model engines you run (Ollama, llama.cpp,
  LM Studio, vLLM, or another Gygax node) and adds a tool-using agent on top. It listens only on `127.0.0.1` until
  you set an API token. No telemetry, no accounts, no update checks.
* **Drones, vehicles and devices.** MAVLink, CAN (SocketCAN, ISO-TP, OBD-II, J1939, CANopen), Modbus, NMEA, ADS-B,
  serial, GPIO and more, plus a virtual autopilot for testing. **Device commands are off by default**; you switch
  them on explicitly.
* **A spiking-neuron simulator** usable from C++, JSON, HTTP, C and Python.
* **Supply-chain logistics** with an append-only ledger and range-aware route planning.
* **SDKs** for native plugins (C and C++), extension processes and Python, plus an MCP client and server.
* **Showcases** in the source: `wargames` (agents defend a bunker; a human can take command) and `arrival` (a
  spiking controller drives a simulated rover; also installed by the packages).

## Get it

| File | For |
| --- | --- |
| `gygax_0.2.0_amd64.deb` | Ubuntu 24.04+ or Debian 13+ on x86-64: `sudo apt install ./gygax_0.2.0_amd64.deb` |
| `gygax-0.2.0-Linux.tar.gz` | x86-64 Linux with glibc 2.38+ and GMP; unpack anywhere and run `bin/gygax` |
| `gygax-0.2.0-alpha.1-source.tar.gz` | Source of exactly this tag |
| `SHA256SUMS` | Check your download: `sha256sum -c SHA256SUMS --ignore-missing` |

Then:

```bash
gygax doctor                 # 20 self-tests, no network needed
gygax serve --engine echo    # a local service on 127.0.0.1:1984 with a built-in test model
```

Point it at a real model with `--engine ollama` (or `llama-cpp`, `lmstudio`, or any `http://host:port/v1`).

**Other platforms:** macOS builds from source with Homebrew's LLVM, and the full test suite passes there in CI.
Windows 11 runs the same scripts through Docker Desktop (see `docs/WINDOWS.md`). Only Linux x86-64 has prebuilt
packages in this release.

## How it was checked

Every package attached here was built by this repository's release workflow from the tagged commit, after the full
test suite passed on that same machine. CI also runs every commit through Linux (clang 18 with lint, clang-tidy and
cppcheck), AddressSanitizer, ThreadSanitizer, a container health check and macOS.

## Fixed since the code was first published

* A crashed MCP server could take the whole service down with it; now it is reported as an error.
* Builds and passes its tests on macOS (Homebrew LLVM), including system information read without `/proc`.
* Several timing-sensitive tests made reliable.
* The project website (GitHub Pages) now publishes.
