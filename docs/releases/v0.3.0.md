# Gygax 0.3.0: Skynet

![Gygax 0.3.0 "Skynet": SatLink satellite tracking](https://raw.githubusercontent.com/magneato/gygax/v0.3.0/docs/releases/v0.3.0.png)

Gygax 0.3.0 looks up. **SatLink** adds satellite tracking for ground stations: it reads two-line elements,
propagates them with SGP4/SDP4, points your antenna, corrects your radio for Doppler, listens with a
software-defined radio, and tells you when the next pass rises. (Named for the satellites, not the film: Skynet is
also Britain's military communications constellation, flying since 1969.)

Gygax is pre-1.0: interfaces may still change between minor releases, and the release notes will say how. Please
report what breaks: [issues](https://github.com/magneato/gygax/issues). 0.3.0 follows the 0.2.0-alpha.1 "Genesys"
pre-release and includes everything in it.

## SatLink

```
$ gygax track --tle examples/satlink/sample.tle --at 51.4779,-0.0015,46 --start 2024-01-01T12:00 --downlink 437.8e6

station 51.4779°N 0.0015°W 46 m

  rise (UTC)            from       peak (UTC)  max el   set (UTC)   to         lasts    doppler rise → set
  2024-01-01 13:22:56   219.5° SW   13:26:02     35.2°  13:29:08    84.7° E     6m11s    +9.21 kHz → -9.22 kHz
  2024-01-01 14:59:15   260.2° W    15:02:37     87.7°  15:05:58    82.8° E     6m43s    +9.93 kHz → -9.93 kHz
  ...
```

* **Exact where it counts.** SGP4 and SDP4 follow Vallado et al., *Revisiting Spacetrack Report #3* (2006),
  including the deep-space lunar-solar terms and the 12- and 24-hour resonances. All 667 states of the reference
  verification set (33 element sets) are reproduced: 666 match the published output to **0.12 mm** in position and
  **0.0009 mm/s** in velocity, and the one where the reference reports an impossible orbit is rejected with the same
  error. The decay case fails the way the reference does, too.
* **Agrees with Skyfield.** Over three days of ISS positions, look angles agree to 0.0003° in elevation, range to
  2.5 m and range rate to 4 cm/s, and both find the same rises, culminations and sets.
* **Doppler from the true range rate,** not from differencing two positions: the satellite's Earth-fixed velocity
  projected on the line of sight. Sidereal time is computed from Unix seconds so the Earth-fixed frame has no
  Julian-date jitter.
* **Passes** with rise and set to 10 ms and culmination to 0.1 s, including satellites that never set.
* **Radio control** through Hamlib `rigctld`, over one connection kept open for the whole pass; refusals
  (`RPRT -11`) are errors, not silent successes.
* **Software-defined radio** over `rtl_tcp`: `gygax track --live --sdr` retunes an RTL-SDR to the predicted carrier
  every second and reports where the strongest signal actually is, and how far it stands above the noise. Underneath:
  an rtl_tcp client, an FFT power spectrum with sub-bin peak estimation, and a phase-continuous mixer that removes a
  sweeping Doppler shift from IQ. In the test suite a simulated sky plays the ISS's true Doppler-shifted carrier with
  a 350 Hz transmitter error; Gygax tunes out the ±10 kHz of Doppler and finds the 350 Hz to within a bin.
* **Everywhere Gygax is:** C++ (`gygax/satlink/satlink.hpp`, `sdr.hpp`), the C ABI (`gygax_satlink_*`), Python
  (`gygax.satlink`, where scripts written for Skyfield's `EarthSatellite`, `wgs84.latlon`, `.altaz()` and
  `find_events` run unchanged, plus `Rig` and `RtlTcp`), the CLI (`gygax track`, with `--live`, `--rig` and `--sdr`),
  and a `gygax doctor` check.
* **Fast:** about 0.5 µs for a complete look at the ISS from a station, 0.7 µs for a geostationary satellite, 17 ms
  for a week of passes.
* **Still yours:** SatLink never downloads elements. You bring the TLEs; `gygax track` warns when they are more than
  two weeks old.

The guide, with the frames, the Doppler sign conventions for uplink and downlink, and the accuracy limits that come
from the elements themselves, is [docs/SATLINK.md](https://github.com/magneato/gygax/blob/v0.3.0/docs/SATLINK.md).

## OHFLOCK

A new showcase to watch: twenty-four small unarmed aircraft hold an air corridor open for a relief convoy at night,
against fighters, a SAM battery, AAA and strike jets. Hundreds of rounds are fired at them; they fire nothing. Lasers
dazzle trackers and paint decoy spots (on sensors only, never people), thrown sound draws the guns' fire, and SatLink
does the rest: Doppler navigation from a 60-satellite relay shell under GNSS jamming (tens of metres), relay windows
for orders from the ground, and the other side's imaging pass predicted and waited out. `ohflock --html` writes a 3D
replay; `ohflock --serve` lets you direct it from gyde; `--no-satlink` shows what the satellites were worth (40 hits
instead of 18 over twelve seeds). See [docs/OHFLOCK.md](https://github.com/magneato/gygax/blob/v0.3.0/docs/OHFLOCK.md)
and the [replay](https://magneato.github.io/gygax/examples/ohflock/ohflock.html).

## Also in this release

* Versions are consistent everywhere: `gygax version` prints `gygax 0.3.0 "Skynet"`; the C ABI, service and packages
  report `0.3.0`; the Python package's version is its PEP 440 form (`gygax.version_pep440()` maps between them, and a
  test keeps them in step). Pre-release labels are limited to `alpha.N`, `beta.N` and `rc.N`, which map one to one
  onto PEP 440 (`0.3.1a1`) and Debian (`0.3.1~alpha.1`) versions; the release workflow checks the whole tag.
* `build.sh` picks the newest clang installed, from 21 down to 18.
* 404 CTest entries and 21 `gygax doctor` checks.

## Get it

| File | For |
| --- | --- |
| `gygax_0.3.0_amd64.deb` | Ubuntu 24.04+ or Debian 13+ on x86-64: `sudo apt install ./gygax_0.3.0_amd64.deb` |
| `gygax-0.3.0-Linux.tar.gz` | x86-64 Linux with glibc 2.38+ and GMP; unpack anywhere and run `bin/gygax` |
| `gygax-0.3.0-source.tar.gz` | Source of exactly this tag |
| `SHA256SUMS` | Checksums for all three, for `sha256sum -c` |

Then:

```bash
gygax doctor                 # 21 self-tests, no network needed
gygax track --help           # satellite passes, Doppler, rig and SDR control
gygax serve --engine echo    # a local service on 127.0.0.1:1984 with a built-in test model
```

**Other platforms:** macOS builds from source with Homebrew's LLVM, and the full test suite passes there in CI.
Windows 11 runs the same scripts through Docker Desktop (see `docs/WINDOWS.md`). Only Linux x86-64 has prebuilt
packages in this release.

## How it was checked

Every package attached here was built by this repository's release workflow from the tagged commit, after the full
test suite passed on that same machine. CI also runs every commit through Linux (clang 18 with lint, clang-tidy and
cppcheck), AddressSanitizer, ThreadSanitizer, a container health check and macOS.
